# Upcoming features

This board shows work that is **not built yet**. Every card comes from Yuyu's own list of future work, [`docs/FUTURE_PHASES.md`](https://github.com/twilighty-abhi/yuyu/blob/main/docs/FUTURE_PHASES.md), which holds only things that are not currently implemented. For what already works, see [What Yuyu can do](/features/feature-list). For what shipped in each release, see the [Changelog](/changelog).

::: warning The priorities are a suggestion
Yuyu's list does not rank its items, and nothing here is a promise or a date. The High, Medium and Low columns are this wiki's own judgement: High means security, privacy and gaps in features that already ship, Medium means planned work with a clear need, and Low means nice to have or only if organisers ask. Change a card's column by editing `docs/.vitepress/theme/roadmap.json`.
:::

## How items leave this board

Yuyu moves an item out of its future-work list only once the code, migrations, tests, configuration and operational requirements are all done. When that happens, the item moves to the [feature pages](/features/feature-list) and appears in the [Changelog](/changelog), and its card here should be removed.
