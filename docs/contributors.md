These are the people who have committed code to Yuyu and its companion repositories, read from GitHub. Thank you.

## Where the counts come from

The counts are GitHub's own contributor counts for each repository's default branch: [Yuyu](https://github.com/twilighty-abhi/yuyu), the Android app, the iOS app and this wiki. Only people with commits are listed, so being a member of the organisation is not enough to appear here. Bots are left out, and a person's commits under different author names are counted once if GitHub links them to the same account.

::: tip Keeping this page current
Run `npm run contributors` in the wiki repository to refresh the list. It needs a GitHub token, either `GITHUB_TOKEN` or a `gh auth login` session, because some of the repositories are private. Then commit the updated `docs/.vitepress/theme/contributors.json`.
:::

Want to be on this list? See [Contributing upstream](/build/contributing).
